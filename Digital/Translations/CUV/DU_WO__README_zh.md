# 屬靈爭戰卡牌遊戲（SWCG）—— 和合本中文版

一套以聖經為本的工具，幫助人把神的話應用在真實生活的處境裡。可以自己安靜默想，也可以當作家庭或小組的遊戲。

重點不在於誰得分多，而在於彼此鼓勵、用神的話彼此建造。

*最後更新：2026-07-19*

---

## 快速上手

1. 把所有檔案下載下來，放在一個好找的資料夾。
2. 用 Chrome、Firefox、Edge 或 Safari 開啟 `DeckShuffle_zh.html`。iPhone 或 iPad 請看下面的**在手機平板上使用**。
3. 還沒選 PDF 時，設定畫面應該會自動打開。如果沒有，點右上角的**設定 ⚙️**。
4. 在 **PDF 檔案**裡，選一副經文牌組：
   * `SWCG_Jingwen_Ri_CUV.pdf`（白天）
   * `SWCG_Jingwen_Ye_CUV.pdf`（夜晚）
5. 勾選**隨機排列**，再按**儲存並開始**。預設會顯示四張經文卡。

### 情境卡（選用）

如果你也有情境卡的 PDF，開啟**設定 ⚙️**，選**＋ 新增群組**，選好情境卡 PDF，並把那個群組的顯示張數設成 1。

**白天**模式適合日常、闔家皆宜的處境；**夜晚**模式處理比較沉重或成人的情境，未必適合年紀小的玩家。

## 怎麼用這些卡

### 個人默想

顯示四張經文卡，想一想眼前真實的處境——一個決定、一份掛慮、一個試探、一項祝福，或一件值得感恩的事。

讀完四張，挑出最貼近的那一段，然後思想：

* 我該記住的真理是什麼？
* 這裡有沒有一個可以信靠的應許？
* 有沒有什麼態度或行動需要改變？
* 今天我可以怎麼實際去行？

你也可以早上先抽四張，等到心裡煩躁、擔憂、受試探、得鼓勵或蒙福的時候，再回頭看它們。

### 家庭或小組玩法

1. 圍成一圈，選出第一位「主述者」。
2. 主述者讀一張情境卡，或自己描述一個真實或假設的處境。沒有人需要透露私事。
3. 其他人各自從手上挑一張經文卡，可以引導、堅固、糾正、安慰或鼓勵主述者。
4. 每個人讀出那段經文裡最相關的部分，簡短說明為什麼挑它。
5. 主述者選出對自己最有幫助、最貼切的一段經文。
6. （選用）出那張卡的人得一分。
7. 每個人把手牌補回四張。
8. 主述者的角色往左邊傳。

可以玩到有人先得五分，也可以完全不計分，單純一起討論哪段經文最合用。

這個遊戲的價值，在於為每個處境領受到寬廣的經文與不同的角度，而不只是贏。

> 情境卡上若有斜體字，那是相關掙扎的提示，不一定要念出來。

## 關於 DeckShuffle

DeckShuffle 是一個通用工具，把 PDF 的每一頁當成一張卡。除了 SWCG 的卡片，也可以拿來用在其他含有問題、活動、圖畫或查經題目的 PDF。

在**設定 ⚙️**裡你可以：

* 選一個或多個 PDF 檔案。
* 指定要用哪幾頁，例如 `1:42`。
* 設定要顯示幾張卡。
* 勾選**隨機排列**來洗牌。
* 新增不同的群組，例如一組放情境卡、一組放經文卡。
* 勾選**記住設定與檔案**。

點一張卡可以全螢幕看。按**換一張**會把那張收走，換下一張上來。

你選的檔案都留在自己的瀏覽器裡，不會上傳到任何伺服器。

## 白天與夜晚模式

### 白天

適合日常處境、家庭、教會小組、年紀較小的玩家，以及個人默想。

### 夜晚

包含比較沉重或成人的情境，未必適合年紀小的玩家。要和兒童或青少年一起用之前，請先自己看過內容。

搭配情境卡時，請讓兩邊模式一致：

* 白天情境卡配白天經文卡。
* 夜晚情境卡配夜晚經文卡。

## 在手機平板上使用

### iPhone 與 iPad

直接用「檔案」App 的預覽開啟 `DeckShuffle_zh.html`，多半不會正常運作——預覽雖然會顯示頁面，卻不一定讓裡面的 JavaScript 完整執行。

比較可靠的作法是裝一個本機網頁伺服器 App，例如 **WorldWideWeb**：

1. 把 HTML 檔和 PDF 放在同一個資料夾。
2. 在該 App 裡選擇這個資料夾。
3. 啟動伺服器。
4. 用 Safari 開啟 App 給的本機網址。

這樣等於把檔案當成一個小型本機網站來開，而不是用預覽模式。

### Android

在 Android 上，請用完整的瀏覽器（例如 Chrome）開啟 HTML 檔，不要只用檔案管理員的預覽。多數手機這樣就夠了。

不同瀏覽器和檔案管理員的行為不太一樣。如果頁面不正常，就改用本機網頁伺服器 App，再用瀏覽器開它給的本機網址。
